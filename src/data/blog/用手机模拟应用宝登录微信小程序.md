# 用手机模拟应用宝登录微信小程序

### 详细步骤：

1. 安装mt管理器软件（修改文件用），墨迹大侠安装包（更新）

2. 在目录/sdcard/下新建文件夹"frida"，一会要将登录文件login.js放在这个目录里边

   ![image-20250905175833799](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20250905175833799.png)

3. 利用抓包工具抓取应用宝登录请求"https://web-a5h5.hanyinkj.cn/auth/auth_sdk/auth.php"的返回参数

   ![image-20250905175959634](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20250905175959634.png)

![image-20250905180031059](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20250905180031059.png)

**替换"uin","authtime","loginkey"三个参数就生成了当前扫码登录的小程序账号，将新的login.js文件放到第二步新建的目录下边**
