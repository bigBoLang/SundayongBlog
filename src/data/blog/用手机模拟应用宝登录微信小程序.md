# 用手机模拟应用宝登录微信小程序

### 详细步骤：

1. 安装mt管理器软件（修改文件用），墨迹大侠安装包（更新）

2. 在目录/sdcard/下新建文件夹"frida"，一会要将登录文件login.js放在这个目录里边

3. 利用抓包工具抓取应用宝登录请求"https://web-a5h5.hanyinkj.cn/auth/auth_sdk/auth.php"的返回参数

	**替换"uin","authtime","loginkey"三个参数就生成了当前扫码登录的小程序账号，将新的login.js文件放到第二步新建的目录下边**

### 增加脚本实现自动复制粘贴参数

1. 找到菜单Rules -> Customize Rules,搜索找到函数OnBeforeResponse，然后在里边添加如下代码，注意修改一下login.js.base的路径
```
static function OnBeforeResponse(oSession: Session) {
        if (m_Hide304s && oSession.responseCode == 304) {
            oSession["ui-hide"] = "true";
        }
        
        // 抓取逻辑 开始
        var targetUrl = "/auth/auth_sdk/auth.php";
        if (oSession.uriContains(targetUrl))
        {
            FiddlerObject.log("===== 目标响应数据 =====");
            FiddlerObject.log("请求地址: " + oSession.fullUrl);
            FiddlerObject.log("响应状态码: " + oSession.responseCode);

			var resBody = "";
			try{
				//尝试正常解码读取响应
				resBody = oSession.GetResponseBodyAsString();
			}catch(e){
				// Gzip解压失败时，读取原始二进制，转成字符串，避免弹窗报错
				FiddlerObject.log("⚠️解压异常，读取原始响应数据，异常信息：" + e.Message);
				var rawBytes = oSession.responseBodyBytes;
				resBody = System.Text.Encoding.UTF8.GetString(rawBytes);
			}

			FiddlerObject.log("响应内容:\n" + resBody);
        }
        
        if (oSession.uriContains(targetUrl))
        {
            FiddlerObject.log("===== 捕获 auth_sdk 响应 =====");
            var resBody = oSession.GetResponseBodyAsString();
        
            //正则匹配uin（数字）
            var rxUin = new System.Text.RegularExpressions.Regex("\"uin\":(\\d+)");
            var matchUin = rxUin.Match(resBody);
            var uin = matchUin.Success ? matchUin.Groups[1].Value : "未获取";

            //正则匹配authtime（数字）
            var rxAuthTime = new System.Text.RegularExpressions.Regex("\"authtime\":(\\d+)");
            var matchAuthTime = rxAuthTime.Match(resBody);
            var authtime = matchAuthTime.Success ? matchAuthTime.Groups[1].Value : "未获取";

            //正则匹配loginkey（字符串）
            var rxLoginKey = new System.Text.RegularExpressions.Regex("\"loginkey\":\"([^\"]+)\"");
            var matchLoginKey = rxLoginKey.Match(resBody);
            var loginkey = matchLoginKey.Success ? matchLoginKey.Groups[1].Value : "未获取";

            FiddlerObject.log("✅ 提取结果：");
            FiddlerObject.log("uin = " + uin);
            FiddlerObject.log("authtime = " + authtime);
            FiddlerObject.log("loginkey = " + loginkey);

            // ========= 文件替换逻辑 =========
            // 【重点】修改这里为你自己文件绝对路径！！
            // ===== 文件替换逻辑 =====
            // 模板文件路径（base模板，不会被修改）
            var templatePath = "C:\\Users\\xxx\\Desktop\\login.js.base";
            // 输出生成的目标文件（每次覆盖）
            var outPath = "C:\\Users\\xxx\\Desktop\\login.js";
            try{
                // 读取模板内容
                var content = System.IO.File.ReadAllText(templatePath);

                // 替换占位符
                content = content.Replace("{{UIN}}", uin);
                content = content.Replace("{{AUTHTIME}}", authtime);
                content = content.Replace("{{LOGINKEY}}", loginkey);

                // 写入新文件，覆盖旧login.js
                System.IO.File.WriteAllText(outPath, content);
                FiddlerObject.log("📁 生成完成！输出文件：" + outPath);
            }
            catch(ex){
                FiddlerObject.log("❌ 文件操作失败：" + ex.Message);
            }
        }
         // 抓取逻辑 结束
    }
```
