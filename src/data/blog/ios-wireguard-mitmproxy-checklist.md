> 本文已隐去真实的服务器地址、VPN 域名、面板地址和账号信息，示例统一使用 `<服务器IP>`、`vpn.example.com` 等占位符。

整套流程只做两件事：

1. 手机通过 WireGuard 隧道，把游戏的鉴权请求交给 mitmproxy；
2. mitmproxy 按设备 ID 改写 `auth.php` 返回的账号凭证。

其余流量（微信、视频、游戏 WebSocket、银行等）都直连，不走隧道。

---

## 0. 每台手机的对应关系

每台手机使用独立的 WireGuard 实例和 UDP 端口，配置不要共用、不要混用：

| 手机 | 配置名 | UDP 端口 | 配置来源 |
|---|---|---|---|
| 第 1 台 | `phone1` | 51820 | 面板「手机实例」→ 二维码 |
| 第 2 台 | `phone2` | 51821 | 面板「手机实例」→ 二维码 |
| 第 3 台 | `phone3` | 51822 | 面板「手机实例」→ 二维码 |
| 第 4 台 | `phone4` | 51823 | 面板「手机实例」→ 二维码 |

端口保持固定，后面迁移服务器时只要端口不变，手机配置就不用重做。

## 1. 安装证书（每台手机一次）

用 **Safari** 打开：

```
http://<服务器IP>:18080/ca
```

1. 点「下载证书 mitmproxy-ca-cert.cer」
2. 弹出「此网站正尝试下载一个配置描述文件」→ **允许**
3. 设置 → 通用 → **VPN 与设备管理** → 点 `mitmproxy` → 右上角 **安装** → 输入锁屏密码 → 再点 **安装**
4. 设置 → 通用 → **关于本机** → 拉到最底 **证书信任设置** → 打开 `mitmproxy` 的开关 → **继续**

> 第 4 步不做，游戏会报网络错误 / 证书错误。
>
> 用微信、QQ 内置浏览器打开可能不触发安装，必须用 Safari。

如果服务器在大陆，未备案域名的 HTTP 访问可能被云厂商拦截，所以证书页建议直接用 IP 访问；域名只用于 VPN 的 UDP 端点。

---

## 2. 导入 VPN 配置（每台手机一次）

1. 电脑或另一台手机打开管理面板 → 「手机实例」→ 找到自己那台 → 点「二维码」
2. 打开 AmneziaWG（或 WireGuard）App → 右上角 `+` → **扫描二维码**
3. 导入后把配置改个名字（如 `phone2`），方便区分
4. 检查配置详情里的 `Endpoint`，端口必须和自己的实例一致：

```
第 1 台  vpn.example.com:51820
第 2 台  vpn.example.com:51821
第 3 台  vpn.example.com:51822
第 4 台  vpn.example.com:51823
```

> 如果之前用的是 IP 地址，不用重新扫码：在 App 里点「编辑」，只把 `Endpoint` 改成域名，保存即可。之后服务器换 IP 只需要改 DNS。

没有二维码时也可以下载 `.conf` 文件，用 App 的「从文件导入」。

---

## 3. 连接 VPN

1. 打开 AmneziaWG → 选中自己那条 → **打开开关**
2. 状态栏出现 `VPN` 图标
3. 回到管理面板刷新 → 「手机实例」里自己那台的 **最近连接** 应显示已连接（几秒内）

> iOS 同一时间只允许一个 VPN 处于启用状态。
>
> 如果装了多条配置，务必确认当前启用的是自己那条。

---

## 4. 绑定游戏账号（每台手机一次）

1. 打开游戏，正常走登录流程（微信 / QQ 登录）
2. 面板顶部 **待绑定设备** 会出现这台手机的设备 ID（显示来源实例和端口）
3. 在抓包机器上抓到这组凭证：`uin` / `authtime` / `loginkey`
4. 面板「抓包直传」→ 把整段抓包内容粘进文本框 → 点「智能导入」：
   - 这个 `uin` 已经有绑定 → 自动更新凭证
   - 是新账号 → 展开设备选择，**默认选中最近活跃的待绑定设备**，确认即可
5. 手机端：游戏 **退出登录 → 重新登录**（或杀掉进程重开）

之后 `auth.php` 会被自动改写，账号就切过去了。

> 抓包数据 **15 分钟内**没完成绑定会自动忽略，需要重新抓一次。
>
> 同一个 `uin` 再次抓包时，旧的匹配链接立即作废，只保留最新的一份。

### 关于安卓抓包

安卓不走 VPN，也不需要设备 ID，但可能和 iOS 共用同一个上传接口。上传时显式标记平台即可，服务端会直接忽略，不会写入凭证、也不会生成匹配：

```bash
curl -H "X-MJDX-Token: $MJDX_TOKEN" \
     -H "X-MJDX: 1" \
     -H "X-MJDX-Platform: android" \
     -H "Content-Type: text/plain" \
     --data-binary @capture.txt \
     http://<服务器IP>:18080/api/capture
```

也可以把 `"platform":"android"` 放进 JSON，或在文本里写一行 `platform = android`。

## 5. 日常使用

- 只想让账号生效：VPN 保持连接即可，游戏正常玩
- 游戏 WebSocket、微信、视频、银行 **不走隧道**，只有鉴权 IP 和 DNS 走
- 不用时可以关掉 VPN；关了账号切换就不生效

---

## 6. 连不上时的自查顺序

| 现象 | 检查 |
|---|---|
| 面板「最近连接」一直是「30 分钟内无连接」 | VPN 开关没开 / 启用了别的配置 / 扫错了二维码 |
| App 里握手一直是 `--` | Endpoint 端口错；或运营商拦 UDP，换 Wi-Fi 试 |
| VPN 连上但游戏报网络错误 | 证书没装、或没开「完全信任」 |
| 游戏进去了但账号没变 | 没绑定；或绑定后没重新登录；或 `authtime/loginkey` 过期，需要重新抓包 |
| 待绑定列表一直空的 | 游戏还没触发 `auth.php`；退出重进一次游戏 |

## 7. 迁移服务器

因为 `Endpoint` 用的是域名，迁移时手机端**理论上零改动**，前提是把密钥和证书原样搬走：

| 要搬的东西 | 说明 |
|---|---|
| `/opt/mjdx/` | 凭证、待绑定、面板密码、各实例密钥、客户端配置、二维码 |
| `/root/.mitmproxy/` | **CA（`mitmproxy-ca.pem`）+ 默认实例的 `wireguard.conf`** |
| `mjdx*.service` | 所有 systemd 单元 |

迁移步骤：

1. 新机装好 mitmproxy、qrencode，按原样放好上面三个目录 / 文件
2. 启动所有服务，确认 `UDP 51820-51823`、面板端口正常
3. 在 DNS 服务商把 `vpn.example.com` 的 A 记录改成新机公网 IP
4. 等 DNS 生效（TTL 60 秒），手机端 **什么都不用做**

> ⚠️ 千万不要在新机上让 mitmproxy 自动生成新 CA。一旦 CA 变了，所有手机都要重新装证书 + 重开完全信任。
>
> 只要 `mitmproxy-ca.pem` 带过去，证书信任就一直有效。

---

## 8. 换手机 / 不用了怎么还原

1. 设置 → 通用 → **VPN 与设备管理** → 删除 `mitmproxy` 描述文件
2. 设置 → 通用 → **关于本机** → **证书信任设置** → 关闭 `mitmproxy`
3. 设置 → 通用 → **VPN 与设备管理** → **VPN** → 删除对应配置（或在 App 里删）
4. 面板里删除对应实例和账号绑定

## 备注

- 全程不需要越狱，不安装 MDM，不获取相册 / 通讯录 / 定位权限
- 证书文件只是公钥，不包含私钥；私钥只在服务器上
- VPN 配置里有这台设备的私钥，不要外发截图或文件
- 本文的服务器地址、域名、设备 ID、账号均已脱敏
