给你一套**稳、安全、能跑小程序**的Mac微信双开方案，首选**官方正式版+重签名分身**（数据隔离、稳定性最高），次选**开源管理工具**（省心）。小程序在Mac微信4.0+版本已支持，按本方案可正常使用。

### 🏆 首选方案：官方微信 + 重签名分身（最稳最安全）
**核心优势**：两个独立App、数据不互通、不碰原版、适配小程序。

#### 1. 准备
- 完全退出微信（右键Dock图标→退出）。
- 确保主微信是**官网最新正式版**（别用测试版）。

#### 2. 一键生成分身（终端复制执行）
打开「终端」，粘贴以下命令并按提示输入开机密码（输入时无显示，正常）：
```bash
# 复制官方原版为WeChat2（数据完全隔离）
sudo cp -R /Applications/WeChat.app /Applications/WeChat2.app

# 修改Bundle ID（让系统识别为新应用）
sudo /usr/libexec/PlistBuddy -c "Set :CFBundleIdentifier com.tencent.xinWeChat2" /Applications/WeChat2.app/Contents/Info.plist

# 强制重签名（必做，否则打不开）
sudo codesign --force --deep --sign - /Applications/WeChat2.app
```

#### 3. 使用与区分
- 启动：双击「应用程序」里的**WeChat2**，与原版同时运行。
- 区分：给WeChat2改图标（右键→显示简介→拖图片到图标），避免点错。
- 小程序：两个微信均可正常打开、使用小程序（在聊天或发现页进入）。

#### 4. 维护
- 微信更新后：需重新执行上述命令重签名WeChat2。
- 卸载分身：直接拖入废纸篓，不影响主号。

### 🧩 备选方案：开源管理工具（更省心）
**工具**：wechat-multi-instance-manager（GitHub开源，安全可信）。
**优点**：一键创建/删除分身、图标自定义、不修改原版、数据隔离。
**步骤**：
1. 从GitHub下载安装。
2. 按指引创建WeChat2实例。
3. 直接启动两个微信，小程序可用。

### ⚠️ 关键提醒
1.  **安全**：不使用第三方插件/注入，不修改官方原包，账号安全性高。
2.  **小程序**：确保主微信为4.0+版本，重签名后分身版本与主号一致，可正常使用。
3.  **风控**：仅用于个人账号，避免营销操作，降低触发风控概率。
4.  **稳定性**：重签名法为当前最优，微信更新后需重签一次。
